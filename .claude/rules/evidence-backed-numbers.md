Never produce a number without measurement, counting, or derivation behind it.
Ban unmeasured time estimates, line counts, confidence percentages, difficulty multipliers, coverage claims, performance predictions without profiling, token/cost guesses, and other invented metrics.
Do not log volatile stats like file counts, line counts, function counts, or agent counts in durable docs; they go stale immediately.
Describe plans as architecture deltas and concrete changes, not numerical guesses.
