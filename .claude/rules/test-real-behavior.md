Tests assert real production behavior, not aspiration. A failing test that catches a real bug is a good test — leave it red, do not make it green by accommodation. The goal is signal, not green CI.
Banned accommodations: monkeypatching production class shapes/signatures/return types to make assertions pass; substituting permissive subclasses that accept fields the production type omits; mocking the asserted-behavior surface itself; loosening predicates to match broken state without naming the regression. These produce theatrical-pass: green test, broken code, zero signal.
When a test catches a real bug, file as a fail-by-design regression with a named ID, document the predicate that flips it green, ship the fix separately. Test stays red until the fix lands.
Mocks allowed as fixture-delivery for inputs — canned responses, synthetic stores, fake transports — when assertions run against deterministic outputs of the real code under test. Mocks banned as substitution for the asserted-behavior surface itself (per unit-tests-no-integration-mocks.md).
Before claiming a fix works, the test that gates it must have FAILED before the fix and pass after — never add a test that already passed against the broken code.
